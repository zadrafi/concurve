# concurve — project memory

R package computing and plotting compatibility (consonance), surprisal,
and likelihood curves/distributions. Version 3.0.0, GPL-3. Previously on
CRAN, **archived 2022-10-03**; currently being resubmitted
(cran-comments.md must always describe a *resubmission*, never a "new
release"). Docs site: <https://stat.lesslikely.com/concurve/>

## Layout

| Path | Contents |
|----|----|
| `R/` | Package source **only** — function/class definitions. Never put top-level executable code here (see below). |
| `dev/` | Quarantined standalone validation/simulation scripts and their outputs (pngs, csvs). `.Rbuildignore`d. Not package code. |
| `vignettes/` | Quarto/Rmd vignettes (knitr VignetteBuilder). Several use Suggests-only packages (ProfileLikelihood, survival) via `library()` — that's fine. |
| `man/` | Generated by roxygen2 — edit roxygen comments in `R/`, not these. |
| `tests/testthat/` | Tests, plus `spelling.R` (aspell against `inst/WORDLIST`). |
| `inst/stan/` | Stan programs (`normal_gfd`, `normal_profile`, `normal_mle`) shipped as **plain text only**. See "Stan integration" below. |
| `tools/` | Maintenance scripts (version-consistency check, bare-import scan). |
| `docs/` | pkgdown site, rebuilt by CI (`Rebuild pkgdown site [skip ci]` bot commits land on master). |

## The dev/ convention (critical)

Scripts with **top-level executable code** — `library()`, `set.seed()`,
`cat()`, `stopifnot()`, `write.csv()`, `ggsave()`, Stan compilation —
belong in `dev/`, never `R/`. (A top-level `new.env()` assignment for a
cache, as in `R/curve_stan.R`, is a definition and is fine.) Top-level
code in `R/` executes during `R CMD INSTALL` / `pkgload::load_all()` and
breaks the build (e.g. `library(cmdstanr)` fails at install;
`pkg::fun()` self-references fail during load_all). Detection scan:

``` sh
for f in R/*.R; do
  grep -lE "^(library|set\.seed|cat|print|stopifnot|write\.csv|system|require)\(" "$f"
done
```

Known dev/ scripts: stan_confidence_distribution.R,
ademp_cd_simulation.R, conf_region.R, empirical_likelihood_cd.R,
forecast_cd_conformal.R, cd_decision_layer.R, greenland_bias_cd.R,
conformal_prediction.R. These have repeatedly been re-created in `R/` —
always run the scan before building.

## DESCRIPTION conventions

- Packages used only conditionally (`requireNamespace()`-guarded) or
  only in examples/vignettes go in **Suggests**, not Imports: pbmcapply,
  ProfileLikelihood, officer, survival, survminer, likelihoodAsy. This
  has been silently reverted multiple times — verify before builds.
- `likelihoodAsy` backs `curve_rstar()`/`curve_mpl()`.
- The project does **not** use renv. If `renv/` or a `.Rprofile`
  sourcing `renv/activate.R` appears, it's unwanted scaffolding — remove
  it (it swaps sessions onto an empty library and breaks devtools).

## Stan integration (decided 2026-09-04)

Stan is a **Suggests + runtime-compile** feature, deliberately *not*
rstantools. `rstan` is in Suggests only; `R/curve_stan.R` provides
`curve_stan()` (draws → concurve object, pure R), `curve_stan_fit()`
(`requireNamespace("rstan")`-guarded; compiles via `rstan::stan_model()`
into a session cache `.stan_model_cache`), and `concurve_stan_file()`
(locates `inst/stan/*.stan`). Tests in `test-curve_stan.R` skip without
rstan and `skip_on_cran()` the `stanc()` parse test.

- **Do not run `rstantools::use_rstan()` / `rstan_create_package()`.**
  It adds Rcpp/RcppParallel/rstan/rstantools to Imports plus a
  `LinkingTo`/`Biarch`/`SystemRequirements` block, and creates `src/`,
  `configure`, `configure.win`, `inst/include/`, `inst/stan/include/`.
  If any of these appear: `git checkout -- DESCRIPTION` and delete the
  untracked scaffolding. A stray `rstanlm/` sub-package from
  `rstan_create_package()` exists at the root; it is `.Rbuildignore`d.
- **auto_write landmine:** `rstan::rstan_options(auto_write = TRUE)`
  (and `rstan::stan_model(..., auto_write = TRUE)`) writes
  platform-specific `normal_*.rds` binaries next to the sources in
  `inst/stan/`, which then ship in the tarball. Never set it when
  compiling the bundled models; `inst/stan/*.rds` is `.gitignore`d, but
  check `ls inst/stan/` before building and `rm inst/stan/*.rds` if
  present.
- `curve_compare()` integrates an interpolant of the interval endpoints
  and fails ("maximum number of subdivisions") on Monte Carlo curves —
  use `plot_compare()` in examples involving `curve_stan()` output.
- `dev/stan_confidence_distribution.R` is the rstan validation script
  (GFD vs exact t, profile via `rstan::optimizing`, coverage sim). Needs
  `devtools::load_all()` first; validated 2026-09-04 with rstan 2.32.7.

## Workflow

``` r
devtools::document(roclets = c('rd', 'collate', 'namespace', 'vignette'))
devtools::check(document = FALSE, args = "--as-cran", cran = TRUE)  # ~90 s
devtools::spell_check()   # WORDLIST entries like yxis/tfrac/emp are real
                          # (digit-adjacent tokens); don't "clean" them
devtools::submit_cran()   # interactive prompts + CRAN email confirmation
```

For a check immune to working-tree churn: snapshot the source to a temp
dir (excluding .git/docs/dev), content-scan `R/`, and check the
snapshot.
