# Deprecated functions in concurve

The functions listed below are deprecated. Please use the listed
alternatives.

## Usage

``` r
plotpint(...)

plotsint(...)

meanintervals(...)

metaintervals(...)

genintervals(...)

corrintervals(...)

survintervals(...)

rev_eng(...)

ggconcurve(...)

plot_concurve(...)
```
