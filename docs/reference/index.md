## Statistical Computations

Compute consonance and surprisal distributions for a wide range of
scenarios, along with likelihood functions.

- [`curve_boot()`](https://github.com/zadrafi/concurve/reference/curve_boot.md)
  : Generate Consonance Functions via Bootstrapping
- [`curve_corr()`](https://github.com/zadrafi/concurve/reference/curve_corr.md)
  : Consonance Functions for Correlations
- [`curve_lik()`](https://github.com/zadrafi/concurve/reference/curve_lik.md)
  : Compute Profile Likelihood Functions
- [`curve_lmer()`](https://github.com/zadrafi/concurve/reference/curve_lmer.md)
  : Consonance Functions For Linear & Non-Linear Mixed-Effects Models.
- [`curve_mean()`](https://github.com/zadrafi/concurve/reference/curve_mean.md)
  : Consonance Functions For Mean Differences
- [`curve_meta()`](https://github.com/zadrafi/concurve/reference/curve_meta.md)
  : Consonance Functions For Meta-Analytic Data
- [`curve_model()`](https://github.com/zadrafi/concurve/reference/curve_model.md)
  : Construct Consonance Functions from Fitted Models
- [`curve_rev()`](https://github.com/zadrafi/concurve/reference/curve_rev.md)
  : Reverse Engineer Consonance / Likelihood Functions Using the Point
  Estimate and Confidence Limits
- [`curve_surv()`](https://github.com/zadrafi/concurve/reference/curve_surv.md)
  : Consonance Functions For Survival Data
- [`curve_wrap()`](https://github.com/zadrafi/concurve/reference/curve_wrap.md)
  : Construct Consonance Functions from Any CI-Producing Function
- [`construct_likelihood()`](https://github.com/zadrafi/concurve/reference/construct_likelihood.md)
  : Construct Likelihood Function for Statistical Models
- [`ggplot_likelihood()`](https://github.com/zadrafi/concurve/reference/ggplot_likelihood.md)
  : Plot likelihood using ggplot2
- [`plot.likelihood_function()`](https://github.com/zadrafi/concurve/reference/plot.likelihood_function.md)
  : Plot likelihood function
- [`curve_from_ratio()`](https://github.com/zadrafi/concurve/reference/curve_from_ratio.md)
  : Construct Consonance Function from Ratio Estimate
- [`plot_all_parameters()`](https://github.com/zadrafi/concurve/reference/plot_all_parameters.md)
  : Plot likelihood for all parameters
- [`plot_ci_levels()`](https://github.com/zadrafi/concurve/reference/plot_ci_levels.md)
  : Plot likelihood with multiple confidence levels
- [`plot_profile_vs_wald()`](https://github.com/zadrafi/concurve/reference/plot_profile_vs_wald.md)
  : Compare profile and Wald confidence intervals
- [`plotly_likelihood()`](https://github.com/zadrafi/concurve/reference/plotly_likelihood.md)
  : Interactive likelihood plot
- [`curve_from_se()`](https://github.com/zadrafi/concurve/reference/curve_from_se.md)
  : Construct Consonance Function from Standard Error

## Database Integration

Connect to databases and construct consonance functions from query
results.

- [`curve_snowflake()`](https://github.com/zadrafi/concurve/reference/curve_snowflake.md)
  : Construct Consonance Functions from Snowflake Query Results
- [`curve_snowflake_batch()`](https://github.com/zadrafi/concurve/reference/curve_snowflake_batch.md)
  : Batch Process Multiple Snowflake Queries for Consonance Functions

## Statistical Graphics

Plot the overall functions that were computed such as the consonance,
surprisal, and likelihood functions.

- [`ggcurve()`](https://github.com/zadrafi/concurve/reference/ggcurve.md)
  : Plots Consonance, Surprisal, and Likelihood Functions
- [`curve_compare()`](https://github.com/zadrafi/concurve/reference/curve_compare.md)
  : Compare Two Functions and Produces An AUC Score
- [`plot_compare()`](https://github.com/zadrafi/concurve/reference/plot_compare.md)
  : Graph and Compare Consonance, Surprisal, and Likelihood Functions
- [`curve_overlap()`](https://github.com/zadrafi/concurve/reference/curve_overlap.md)
  : Calculate Overlap Between Consonance Functions
- [`plot_multi()`](https://github.com/zadrafi/concurve/reference/plot_multi.md)
  : Plot Multiple Consonance Functions
