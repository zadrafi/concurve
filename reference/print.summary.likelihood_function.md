# Print a likelihood function summary

Print a likelihood function summary

## Usage

``` r
# S3 method for class 'summary.likelihood_function'
print(x, digits = 4, ...)
```

## Arguments

- x:

  A `summary.likelihood_function` object

- digits:

  Number of digits for printing numeric values

- ...:

  Additional arguments (unused)

## Value

Invisibly returns `x`

## Details

Prints the coefficient table, dispersion, log-likelihood, AIC, and BIC.
